# user_active_time

Монитор активности пользователя Windows. Работает без прав администратора.

Считает, сколько времени за день ты был за компьютером и сколько из него действительно работал (мышь/клавиатура), показывает это виджетом на рабочем столе, складывает дневные JSON-отчёты и строит по ним тепловую карту и отчёты за период. Различает две нормы — присутствие и активность (рабочие часы минус перерыв).

Документация — два HTML-файла в [`docs/`](docs/), открываются в любом браузере и из меню ❓ приложения:

- [**Техническая документация**](docs/developer_guide.html) — устройство: потоки, модель активного времени, форматы файлов, конфиг, реестры расширений, сборка, версионирование.

## Быстрый старт

```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
start.bat
```

Внешние пакеты (`pystray`, `Pillow`) нужны только для значка в трее — без них всё остальное работает. Данные пишутся в `C:\Users\<пользователь>\active_time\`.

Версия — в `version.py` и в меню ❓ → «О программе», что нового по версиям — в [`CHANGELOG.md`](CHANGELOG.md). Релиз: `python scripts/release.py "описание"` (см. [`scripts/release.md`](scripts/release.md)).
