# Чейнджлог

Что поменялось в каждой версии, коротко и по-человечески. Номер версии сам по
себе ничего не говорит (CalVer считает релизы, а не фичи — см. `version.py`),
поэтому «что нового» живёт здесь.

Как вести: каждая законченная доработка добавляет строку в раздел
**Не выпущено**. При релизе `scripts/release.py` переименовывает этот раздел
в номер версии с датой и кладёт файл в релизный коммит; пустой раздел скрипт
не выпускает.

## Не выпущено

- Внутреннее: разбор дневного отчёта вынесен из окна просмотра в `modules/report_reader.py` (без tkinter) и покрыт тестами. Поведение не менялось.
- Внутреннее: `constants.py` разделён на общие константы, тексты интерфейса (`texts.py`) и Windows API (`winapi.py`). Поведение не менялось.
